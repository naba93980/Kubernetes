CRUD:-
kubectl create deployment [name] --image=[image name]
kubectl edit deployment [name]
kubectl delete deployment [name]

Status of different k8s components:-
kubectl get nodes | pod | services | deployment | replicatset
kubectl get nodes | pod | services | deployment | replicatset -o wide -> more details
kubectl get nodes | pod | services | deployment | replicatset -o yaml -> > file.txt -> put the output in file
kubectl get ingress
kubectl get namespaces

Debugging pods:- 
kubectl logs [pod name] -> Log to console
kubectl exec -it [pod name] --bin/bash -> Get Interactive Terminal
kubectl describe resource [resource name] -> get info about resource

Use configuration file for CRUD:-
kubectl apply -f [file name] -> apply a configuration file
kubectl delete -f [file name] -> delete with configuration file -> delete all components created using the config file.
